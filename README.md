# Koutio design skills

This repository contains reusable design guidance for Koutio Club.

The main skill is located at `skills/koutio-design-studio/` and covers:

- graphic design and branded communication;
- sports-space planning and circuit flow;
- responsive web and UI design.

Exact logos, fonts, color values, dimensions, and safety constraints remain source-of-truth inputs. The skill must inspect or request them instead of inventing them.
