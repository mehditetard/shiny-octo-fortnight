# Communication graphique

## Construire la hiérarchie

Organiser chaque support autour de trois niveaux maximum :

1. message principal ;
2. information qui le rend crédible ou utile ;
3. action attendue.

Si tout paraît important, raccourcir le contenu au lieu de réduire toute la typographie.

## Adapter le support

- **Publication** : compréhension immédiate dans le fil, preuve visible, légende complémentaire.
- **Story** : une idée par écran, zones sûres, action rapide, séquence courte.
- **Couverture de Reel** : titre bref placé pour rester lisible dans les différents recadrages.
- **Flyer** : bénéfice, offre, modalités, contact et respiration suffisante.
- **Planning** : lecture par jour et par heure avant toute décoration.
- **Panneau** : destination et direction dominantes ; détails secondaires seulement si lisibles à distance.
- **Vitrophanie** : composition pensée à l'échelle du vitrage, visibilité intérieure/extérieure et fichier de pose exploitable.

Respecter le ratio demandé : 16:9, 9:16, 4:5, 1:1 ou format d'impression. Ne pas étirer une maquette conçue pour un autre ratio ; recomposer.

## Utiliser les textes exacts

Composer les textes, flèches, horaires et logos dans un outil de mise en page ou en vectoriel. Ne pas les cuire dans une image générée lorsqu'ils doivent rester exacts ou modifiables.

Pour une flèche, vérifier séparément la destination et le sens. Pour plusieurs directions, tester le panneau depuis le point de vue réel de l'usager.

## Créer une campagne

Définir :

- une accroche ;
- un principe visuel ;
- un style de photo ou d'illustration ;
- une règle de placement du logo ;
- un appel à l'action ;
- une logique de déclinaison.

Créer d'abord le support le plus contraignant, puis adapter les autres. Prévoir une version avec peu de texte et une zone facilement actualisable pour les dates, horaires ou tarifs.

## Livrables recommandés

- master éditable ;
- exports web adaptés aux ratios demandés ;
- PDF d'impression si nécessaire ;
- polices ou substitutions documentées ;
- liste des textes et informations vérifiés ;
- aperçu en situation pour un panneau ou une vitrophanie.
