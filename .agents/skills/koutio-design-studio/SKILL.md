# Koutio Design Studio

## Mission

Transformer un objectif concret en design distinctif, crédible et exploitable. Maintenir une seule identité Koutio tout en adaptant la hiérarchie, le format et le niveau de précision au support.

Ne jamais confondre un beau concept avec une solution validée. Pour l'aménagement, séparer systématiquement ce qui est observé, supposé et à confirmer.

## Choisir le mode de travail

Sélectionner un ou plusieurs modes :

1. **Graphisme** : réseaux sociaux, affiches, flyers, signalétique, vitrophanie, planning et campagne.
2. **Espace sportif** : implantation du matériel, circulation, capacité, coaching, rangement et circuit.
3. **Web/UI** : site, landing page, réservation, planning, offre, interface ou design system.
4. **Campagne intégrée** : décliner une même idée sur plusieurs modes sans simplement recopier la mise en page.

Lire uniquement les références nécessaires :

- identité et ton : `references/brand-system.md` ;
- graphisme : `references/graphic-design.md` ;
- espace sportif : `references/sports-space.md` ;
- web/UI : `references/web-ui.md` ;
- contrôle final : `references/quality-gate.md`.

## Suivre le workflow

### 1. Définir le résultat utile

Identifier :

- le public ;
- l'action attendue ;
- le canal ou le lieu ;
- le format et les dimensions ;
- le message prioritaire ;
- les éléments obligatoires ;
- la date, le budget et les contraintes de production ;
- le fichier final attendu : image, source modifiable, plan, code ou ensemble de déclinaisons.

Poser au maximum trois questions lorsque leur réponse change réellement la solution. Sinon, avancer avec des hypothèses réversibles et les signaler.

### 2. Inspecter les sources

Examiner les logos, photos, vidéos, plans, mesures, textes, supports existants et composants de code avant de proposer une direction.

Considérer comme sources de vérité :

- les logos fournis ;
- les valeurs de couleurs et polices officiellement communiquées ;
- les dimensions relevées sur place ;
- les fiches techniques des équipements ;
- les composants et tokens déjà présents dans le code ;
- les obligations réglementaires vérifiées auprès de sources officielles.

Ne jamais inventer un code couleur exact, une mesure, une capacité, une norme ou un dégagement de sécurité.

### 3. Reformuler le brief

Produire une reformulation courte comprenant : objectif, public, support, idée directrice, contrainte dominante et critère de réussite.

Signaler immédiatement toute contradiction. Par exemple, trop de texte pour une story, trop de matériel pour la surface disponible ou une interface séduisante qui cache l'information principale.

### 4. Choisir une idée forte

Proposer une direction principale cohérente. Ajouter des variantes uniquement lorsqu'elles représentent de vraies stratégies différentes.

Éviter les solutions fitness interchangeables : silhouettes découpées, dégradés néon systématiques, diagonales décoratives sans fonction, slogans artificiels, fausses salles premium et banques d'images sans lien avec le lieu.

Privilégier :

- les personnes et espaces réels ;
- les gestes crédibles ;
- une composition reconnaissable ;
- un message lisible en deux secondes ;
- un détail local ou matériel qui ancre le visuel à Koutio.

### 5. Choisir le bon outil de production

- Utiliser la génération d'image pour une photographie, une illustration ou un rendu d'ambiance.
- Utiliser l'édition d'image pour modifier une photo existante sans reconstruire inutilement le lieu ou les personnes.
- Utiliser une mise en page éditable, du vectoriel ou du code pour le texte exact, les panneaux, les tableaux, les plannings et les logos.
- Utiliser un plan coté ou un schéma précis pour valider un aménagement ; réserver le rendu photoréaliste à la communication du concept.
- Travailler dans le code natif et les composants existants pour une interface déjà implémentée.

Ne jamais demander à un générateur d'image de garantir seul l'orthographe, un logo fidèle, un plan à l'échelle ou une cote technique.

### 6. Construire et vérifier

Appliquer le système de marque, la hiérarchie et les règles propres au mode choisi. Vérifier le travail avec `references/quality-gate.md`.

Pour les sujets spatiaux ou réglementaires, vérifier les informations susceptibles d'avoir changé auprès de sources officielles avant de les présenter comme certaines.

### 7. Livrer clairement

Fournir :

- le résultat principal ;
- les formats ou vues demandés ;
- les hypothèses importantes ;
- les éléments restant à confirmer ;
- les recommandations d'export, d'impression ou d'implémentation ;
- un fichier modifiable lorsque le brief le demande.

Ne pas noyer la livraison sous des explications. Présenter d'abord ce que la personne peut utiliser.

## Coordonner les trois domaines

Lorsqu'un projet combine graphisme, espace et web :

1. Définir une idée de campagne unique.
2. Créer un petit noyau partagé : promesse, palette validée, typographie, style photographique, ton et appel à l'action.
3. Adapter chaque support à son usage réel.
4. Préserver la reconnaissance sans imposer une mise en page identique partout.
5. Tester le parcours complet : voir, comprendre, se repérer, réserver ou venir.

## Gérer les itérations

Quand une correction cible un élément précis, verrouiller les éléments déjà validés. Ne pas changer une photo, un nom, un logo, une orientation de flèche, un équipement ou une composition non concernés par la demande.

Avant chaque nouvelle version, lister mentalement :

- ce qui doit changer ;
- ce qui doit rester strictement identique ;
- le test qui prouvera que la correction est réussie.

Comparer la nouvelle version à la demande précédente avant livraison.
